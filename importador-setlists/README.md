# Importador de setlists — MM IBNM

Ferramenta estática em `importador-setlists/index.html`. Abre no navegador, sem login, backend ou envio do histórico para a nuvem. Para pré-visualizar localmente: `python3 -m http.server 8000` na raiz do repositório e acesse `http://localhost:8000/importador-setlists/`.

1. Exporte a conversa do WhatsApp **sem mídia** e selecione o arquivo `.txt` (ou cole o texto).
2. Escolha o intervalo **de envio das mensagens**, inclusive as duas pontas. A data dos cultos pode cair fora do intervalo. Mensagens sem envelope de data (texto colado) são analisadas como um único setlist; nesse caso o ano omitido é inferido da data inicial escolhida.
3. O reconhecedor procura cabeçalhos `MÚSICAS DA SEMANA`, `MÚSICAS DA PRÓXIMA SEMANA` ou `SETLIST` e extrai **todas as seções dentro dessas listas semanais** que contenham músicas em linhas iniciadas por `-` ou `•`: quarta-feira, EBD, culto da noite, sexta, sábado e outros eventos. Datas explícitas no evento prevalecem; se não houver data, usa o dia da semana indicado no cabeçalho da seção e o período semanal. Sem datas no cabeçalho semanal, usa a semana da mensagem (ou a seguinte, quando estiver escrito “próxima semana”). Se não houver informação suficiente, a seção continua na prévia, com a data em destaque para preenchimento obrigatório antes de exportar. Seções datadas de culto fora de listas semanais também são reconhecidas. Editar/remover registros na prévia antes de baixar. Mensagens repetidas **não são deduplicadas automaticamente**.
4. Baixe o JSON (array de objetos) ou CSV (UTF-8) com as colunas exatas da tabela `public.musicas_cantadas` do repositório `adaiascearataiana-gif/mmibnmapp`: `data`, `dia`, `evento`, `musica`, `artista`, `tom`, `web`, `ordem`. `tom` e `web` ficam vazios quando não estão na lista; `ordem` começa em 1. O banco gera o `id` automaticamente.
5. Para inserir, no painel do Supabase do projeto MM IBNM, abra **Table Editor → musicas_cantadas → Import data from CSV** e envie o CSV. Confira a prévia/mapeamento de colunas antes de confirmar. O JSON também pode ser usado em uma importação programática, mas não é gravado automaticamente. A tabela só permite escrita a administradores pelo app/API; a importação pelo painel exige acesso autorizado ao projeto. Confira duplicatas existentes antes de importar.

**Hinos:** `Hino CC 05 - Presença Divina` vira `musica: "Presença Divina - 05"`, `artista: "Cantor Cristão"`. `Hino 410` sem indicação de hinário mantém o prefixo e deixa o artista em branco para conferência. Anotações entre parênteses são removidas. Cada linha com medley (`/`) permanece como um registro, para revisão manual.

O parser funciona com os formatos comuns Android (`28/10/2026 19:30 - Nome: ...`) e iOS (`[28/10/2026, 19:30:00] Nome: ...`). Se o formato de exportação diferir, confira a prévia: nenhuma linha é escrita no banco. Testes: `node --test importador-setlists/parser.test.js`.
